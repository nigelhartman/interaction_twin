A better mesh helps, but it cannot fill every missing field. SAM 3D is a geometry upgrade. It does not automatically provide measured scale, a robot grasp, correct friction, a collision-free path or evidence that an object is seated.

FIRST PHYSICS EXPERIMENT

One rigid part. One fixed opening.

Use an earbud or another rigid part and a fixed, open receptacle. Keep the first task simpler than a flexible wallet.

  1. Verify shape and one metric dimension. Define a shared world frame and the desired insertion frame.
  2. Build separate visual and collision meshes. A single convex hull can seal the opening that the part needs to enter.
  3. Choose an existing robot and parallel-jaw gripper with known dimensions and joint limits.
  4. Author a grasp and pregrasp pose. Check clearance and solve reachability for that specific robot.
  5. Run passive settling, grasp/lift, transfer and contact insertion as separate tests.
  6. Define success by observable pose, penetration, stability and contact criteria. Save failed trials too.
IMPLEMENTATION TARGET

MuJoCo first. Isaac later.

MuJoCo: a small reproducible scene is a practical first contact experiment. Reference a known robot asset, add reviewed rigid bodies and collision shapes, and define task resets and success checks. None of this has been executed yet.

Isaac Sim / Isaac Lab: use USD assets, supported articulation/robot imports and an explicit task configuration. Add resets, observations, actions and rewards after the asset and contact behavior are validated.

Training: a human demonstration can suggest task order and goals. It is not a robot control trajectory. Robot-specific retargeting, grasp planning and physics validation come first.
