THE META PIPELINE

Shape, motion and meaning.

  1. 01

    Find & track

    Muse discovers candidate parts and actions in the video. SAM 3.1 supplies visible-part masks.

  2. 02

    Generate parts

    SAM 3D Objects generates draft meshes from selected source views and masks.

  3. 03

    Connect & describe

    Muse proposes relationships and steps. Geometry code fits estimated joints; the object program binds them to source evidence.

  4. 04

    Review & curate

    Role reviews and deterministic checks guide bounded repairs. The owner approves the exact version before public retrieval.

Generated shape and motion are estimates. Review does not establish metric accuracy, contact, grasp stability or successful insertion.

Implementation & what we built +

The custom contribution

Interaction Twin connects perception outputs into a source-bound object program: component identities, estimated joint frames and angles, demonstrated steps, exact artifact references and uncertainty. The browser, approval workflow and read-only MCP tools use the same curated records.

  • Object programs ↗Descriptive parts, joints and source bindings.
  • Bounded workflow ↗Build, compare, stop and approve exact revisions.
  • Muse role prompts ↗Evidence, geometry, mechanics and semantics.
  • Curated catalog ↗Shared records for people and agent tools.
  • Read-only MCP ↗Search, inspect and retrieve saved artifacts.

Review scopes stay explicit

Hosted role reviewers use separate prompts to the same Muse model; they are not independent models. The default hosted role packet contains text metadata, not source images or meshes. Source/render visual audits are a separately enabled workflow. Code checks validate source hashes, artifact structure, IDs, joint contracts and declared evidence; they do not certify faithful geometry.

Repairs stop, then you decide

The workflow allows an initial build and up to two targeted repair rounds. It compares revisions where evidence is comparable and stops for regression, insufficient evidence, budget or the round limit. An owner must approve the exact result. Private feedback memory supplies retrievable guidance for later prompts; it does not train model weights.

The browser robot is a separate tool

The robotics workbench compiles supported instructions locally into a typed task and runs bounded kinematics in Three.js. It makes no Muse call and does not simulate grasp forces or insertion. The separate Newton bench replays a saved CPU contact experiment under assumed parameters.

Meta supplies the perception and reasoning models. The source-bound program, curation, checks, browser experience and reusable MCP handoff are the project’s integration work. This page illustrates that architecture; it is not a recording of a live inference run.
