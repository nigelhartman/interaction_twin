AGENT CONNECTION GUIDE

One library.
Parts, actions and evidence.

This guide describes the curated Interaction Twin catalog. Use the same origin as this page for all relative API and asset URLs. Reading the catalog runs no inference and requires no API key.

1. Explore the saved public catalog

This is a static demonstration. Browse the library or read its saved catalog JSON. A live HTTP API and hosted MCP endpoint are not running here. To use MCP tools, run the local project as described below.

2. Inspect before proposing a use

  • Follow the returned source-linked program and exact asset references. When a derived_assembly reference is available, it describes the current reviewed refinement. Its component_assets[].native_glb references select the refined parts; original_native_glb preserves their original SAM 3D lineage.
  • Retrieve a returned artifact from this app at /files/<path>, using its exact declared path, sha256 and bytes. For example, a returned data/…/scene.json path maps to /files/data/…/scene.json. Only curated allowlisted artifacts are available; do not invent paths.
  • An optional source_appearance_states_ref points to observed RGB appearance states. Follow its exact saved patch and source references only when needed; preserve unknown intervals, native fallback and its display policy. These states do not simulate electronics or change the downloaded GLBs.
  • Component tracklets are candidate identities; they are not automatically verified physical objects. Describe geometry, connection estimates, demonstrated steps and missing observations before suggesting a robotics task.
  • Use returned source timestamps when citing evidence. A sample index or an ID suffix is not a time in seconds. Download only the program or component the user needs; geometry, scale, contact and physical simulation remain unverified.

3. Optional: connect the local MCP server

The project also includes a read-only local stdio MCP server. There is no hosted MCP endpoint. If the user has a local checkout with its MCP runtime installed, configure their MCP client to launch:

command: <checkout>/.venv-mcp/bin/python
args: [<checkout>/scripts/serve_twin_mcp.py, --curated]

After discovering an exact twin ID, call describe_twin, then request the current reviewed refinement:

{"name":"get_derived_assembly","arguments":{"twin_id":"<ID returned by search_twins>"}}
{"name":"list_derived_artifacts","arguments":{"twin_id":"<the same exact twin ID>"}}

A declared_geometric_derivative response contains the current artifact reference and document. If the response is unavailable, keep that limitation explicit and inspect the original outputs. get_kinematics returns the original native connection estimates; get_generated_candidate returns original SAM 3D geometry and source inputs. Neither substitutes for an available reviewed refinement.

If describe_twin lists observed_surfaces, call get_observed_surfaces to inspect source-visible surface observations and their exact resource URIs. These use estimated monocular depth and source RGB; hidden surfaces and numerical material-joint parameters remain unknown. Keep these separate from the original SAM meshes and kinematics.

list_derived_artifacts returns exact uri, sha256, bytes, mime_type and roles for the current declaration, parts, scene and audits. Optional source appearance patches and cable observations are included when declared. Use your MCP client’s read_resource operation with the returned twin://…/derived-artifacts/… URI; decode its binary content and verify its SHA-256 and byte count. Select the resources you need, rather than downloading everything.

Artifact IDs belong to one twin and its current approval. If an approval changes, list again; do not construct IDs or substitute paths. This remains curated-only even in an owner’s private MCP session. Owner uploads, feedback and unapproved working revisions are excluded. Large GLBs should use stdio or Streamable HTTP; the tested legacy SSE client has a 1 MiB event limit.

Configure your MCP client with the local server command above. A localhost address is reachable only from the computer running this app; if your agent cannot reach it, report that access limitation.
