# Public release scope

Interaction Twin was developed by Nigel Hartman for the Meta Global AI Developer Hackathon 2026. The public repository contains selected custom application source, frontend templates, tests and documentation. The `gh-pages` branch contains a separate frozen, read-only demonstration.

The custom work covers the descriptive interaction/object-program representation, model orchestration, evidence and quality checks, review and approval workflow, curated human/agent access, MCP transport, exports and browser task authoring. The [implementation map](technical-overview-20261104.md#custom-implementation-map) links those capabilities to source files. Meta and upstream authors provide the models and SDKs. The repository does not redistribute model weights or imply ownership of their implementations.

The public demo includes five owner-recorded example families. The YouTube-origin camera recording remains excluded pending confirmed reuse rights. Generated geometry and source-visible surfaces are draft outputs, not measured physical assets. Media is presented for project demonstration; no broad third-party asset license is implied.

The trailer uses project graphics, owner-recorded footage, a local synthetic voice and original procedural instrumental music. It uses no imported stock music. The extended film distinguishes illustrated review logic, actual saved MCP retrieval and authored robot motion.

No project-wide open-source license has been granted. Applicable upstream terms and notices remain in force. The vendored Three.js notice is in [`app/workspace/robot-vendor/LICENSE`](../app/workspace/robot-vendor/LICENSE); it covers that dependency, not the project as a whole. Obtain and use Meta models, weights and SDKs under their respective upstream terms.

Private uploads, owner accounts, approval records, feedback memory, budget ledgers, environments, cluster configuration and credentials are excluded. Saved artifacts are selected separately from application source. The static website has no private admin or upload routes, inference endpoint or hosted MCP runtime.

The source manifest describes an earlier code-only preparation; the public-release inventory records the exact subsequently prepared release files. The lightweight review recipe has separately been installed in a fresh Python 3.12 environment and checked with synthetic fixtures and an empty application startup; see [source setup](source-setup.md). This does not reproduce complete new-video inference or a GPU run.

The final competition declaration of contribution dates and all contributors remains the submitter's responsibility. This source release is separate from submitting the hackathon form.
