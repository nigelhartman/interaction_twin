# Cobalt Motion

Interaction Twin's marketing should look like its product: precise, quiet and spatial. The permanent opening is the existing cobalt logo, **Interaction Twin**, and **“Show it once. Keep how it works.”** The video then moves quickly into actual footage. The machine-readable context is [marketing-brand.json](../config/marketing-brand.json).

Use off-white surfaces, near-black text and cobalt accents. Keep the existing logo intact. Use bold, sentence-case headlines and regular Arial body text, generous margins and one message per scene. Segmentation colours may remain in source footage; they do not become the brand palette.

The opening and closing each last about two seconds. A restrained fade/scale introduces the logo. Use short crossfades, clean cuts and an occasional cobalt wipe. Avoid flash transitions, glitch effects, particles and constantly moving text. Preserve the full filmed interaction with a contain layout; portrait and square versions should use an intentional composition instead of chopping off the object.

The story is **real interaction → separated parts → connected description → reusable task**. For an individual twin, show the source and result. For a pack, make the component range clear. For a pipeline film, show actual masks, geometry and the object program. For robotics, show the working task preview and identify authored staging. Never replace “robot task authoring” with a claim that a robot policy was trained or a physical interaction succeeded.

Use quiet instrumental electronic music with a clean pulse. The default is the project's original procedural instrumental. Imported Pixabay tracks retain their track page, contributor, import date, audio hash, licence acknowledgement and any certificate/Content ID information. Pixabay permits music in a larger creative video; some tracks can still trigger automated claims. Its documented API provides image/video search, so the app must not invent a music-search API. See [Pixabay's API documentation](https://pixabay.com/api/docs/), [licence summary](https://pixabay.com/service/license-summary/) and [music FAQ](https://pixabay.com/service/faq/).

The marketing agent receives approved facts, available source clips, this guide and scoped owner feedback. It chooses an editable storyboard, proposes X/LinkedIn copy, checks unsupported claims and renders a private revision. Feedback creates another revision and preserves the previous one. Owner approval releases a download package; posting remains a separate human action.

Useful feedback includes “show the result earlier,” “slower captions,” “less text,” “more source footage,” “quieter music,” or “use the robotics sequence.” Persistent preferences should be visible and revocable. Feedback is editing guidance, not evidence that geometry, physics or a model release has changed.
